# 🎬 Seedance AI Video Generator (OpenRouter)

Удобный локальный веб-интерфейс на базе **Gradio** для генерации видео через **OpenRouter Video API** с использованием моделей семейств **ByteDance Seedance 2.0 / 2.5**.

Поддерживает продвинутую мультимодальность с референсами: изображения, видео и аудио.

---

## ✨ Возможности

- 🤖 **Поддержка моделей:**
  - `Seedance 2.0 Fast`
  - `Seedance 2.0`
  - `Seedance 2.0 Mini`
  - `Seedance 2.5`
- 📁 **Мульти-референсы (Multi-modal input):**
  - До **9 изображений** (передаются напрямую в Base64)
  - До **3 видео** (автоматическая загрузка через Catbox для создания публичного URL)
  - До **3 аудио** (автоматическая загрузка через Catbox для создания публичного URL)
  - Поддержка тегов в промпте: `@Image1`, `@Image2`, `@Video1`, `@Audio1` и т.д.
- ⚙️ **Гибкая настройка:**
  - Разрешение: `480p`, `720p`, `1080p`
  - Соотношение сторон: `1:1`, `9:16`, `16:9`, `4:3`, `3:4`
  - Длительность видео (от 4 до 15 секунд)
  - Автоматическая генерация аудио/звуковых эффектов к видео
  - Фиксация сида (`Seed`) для воспроизводимости
- 🌐 **Поддержка Прокси (HTTP/HTTPS/SOCKS5):** работа с API без необходимости включения глобального VPN.

## 🚀 Быстрый старт

### 1. Клонирование репозитория
```bash
git clone https://github.com/DEDBW/Seedance.git
cd Seedance
```

### 2. Запуск на Windows
Просто запустите файл:
```bat
run.bat
```
Скрипт сам проверит наличие Python, при необходимости установит зависимости (`gradio`, `requests`) и запустит веб-интерфейс.

### 3. Ручной запуск (Windows / Linux / macOS)
1. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
2. Запустите приложение:
   ```bash
   python app.py
   ```
3. Откройте в браузере: `http://127.0.0.1:7860`

## 🔑 Настройка API-ключа и Прокси

1. Зарегистрируйтесь на [OpenRouter.ai](https://openrouter.ai/) и получите API-ключ.
2. При первом запуске в интерфейсе откройте блок **⚙️ Настройки API и Подключения**.
3. Введите ваш ключ в поле **OpenRouter API Key**.
4. (Опционально) Если вы находитесь в регионе с ограничениями, в поле **Прокси** укажите прокси-сервер в одном из форматов:
   - `http://127.0.0.1:10809`
   - `http://user:password@ip:port`
   - `socks5://127.0.0.1:10808`
5. Нажмите **💾 Сохранить** (настройки сохранятся в файл `config.json`, который автоматически скрыт из Git через `.gitignore`).
